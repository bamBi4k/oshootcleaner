OhShootCleaner is a lightweight Android cleaner and optimizer that uses Shizuku to perform privileged system operations, without requiring root.

Features:

* Clean app caches and residual files via privileged APIs
* Optimize background processes using Shizuku's privileged bridge
* No root required, works on Android 8.0+
* Fully offline, no analytics, no telemetry, no trackers
* Material 3 UI with four built-in pastel themes
